## 2025-02-28 - Missing Labels & Async Success State Announcements in Single-Input Forms
**Learning:** Single-input forms (like newsletter signups) frequently omit explicitly associated `<label>` tags (relying only on placeholders) and lack screen reader announcements when async operations succeed, leaving assistive tech users without context or confirmation.
**Action:** Always include a visually hidden (`sr-only`) `<label>` tied to the input via `id`/`htmlFor`, add a `submitting` state with loading feedback, and ensure success states are announced using `role="status"` and `aria-describedby`.
